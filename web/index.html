A Timex/Sinclair 2068 on the ESP32-P4

With a TS-Pico, on the Elecrow CrowPanel Advanced 7". Version {{VERSION}}.

1. Install the firmware

  1. Plug the panel's UART USB-C port into this computer.
  2. Press Install and choose the port: a CH340, wchusbserial or USB Serial.
  3. It writes MicroPython, the emulator, the TS-Pico firmware and the menu, replacing what's on the board. About two minutes.
  4. When it says the installation is complete, reset the panel: press its reset button, or unplug it and plug it back in. It stays in the installer's mode until then.
This browser can't reach a serial port. Use Chrome or Edge on a computer. The page needs to be opened over https.

Want Elecrow's demo back later? Save it first: esptool --chip esp32p4 read-flash 0 0x1000000 crowpanel-factory.bin. A paired Bluetooth keyboard needs pairing again after installing.

2. Make the microSD card

  1. Download the card files and unzip them onto a FAT32 microSD card.
  2. Put the card in the panel and press reset. The TS2068 starts with the TS-Pico ROM.
