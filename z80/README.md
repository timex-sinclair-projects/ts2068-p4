# z80

Fuse's Z80 core, lifted from `third_party/fuse-tspico/z80` (tag `tspico-v1.10.0-1`, `a43958d`), GPL-2.0-or-later. **This is the emulator's Z80 core** (docs/DECISIONS.md, D5). It was one of two Phase 2 candidates. The other, ESPectrum's Z80_JLS, is in `z80_jls/` behind the same interface, and was slower on the P4 (2.9 ms a frame against 2.5).

**Checked:** Fuse's own core tester (`test/z80`, `make -C test/z80 check`) passes all 1,356 tests in `tests.in`. That's every register, T-state and memory and port access, including contention. Both builds pass: `HAVE_ENOUGH_MEMORY` (prefixed opcodes inlined in one switch) and without it (one function per prefix).

Frank Cringle's exercisers pass too (`make -C test/z80 zex`, 2026-10-30): zexdoc and zexall, 67 of 67 tests each, documented and undocumented flags. That's 46.7 billion T-states, about 32 s each on the Mac. `test/z80/zexrun.c` runs them as CP/M programs.

| `z80_macros.h` | `z80/z80_macros.h` | Includes `z80_glue.h`. `IS_CMOS` is `Z80_IS_CMOS` (0, NMOS). The contention macros moved to `z80_glue.h` |

| `z80_ops.c` | `z80/z80_ops.c` | The per-instruction hook list (`z80_checks.h`: profiler, RZX, automation, debugger, and the Beta, +D, DISCiPLE, Opus, Didaktik, IF1, DivIDE, DivMMC, uSource, uSpeech, Multiface, Spectranet and SVG traps) is gone, and with it the computed-goto setup. | `z80_core.h` | ours | What the machine and tests call a core through: init, reset, run, interrupt, end of frame, registers. Both cores implement it |

## What the machine provides

From `z80_glue.h`:

- `tstates`, `event_next_event`, `event_register`, `event_add`
- `readbyte`, `readbyte_internal`, `writebyte`, `readport`, `writeport`
- `z80_interrupt_length`, `z80_int_disabled`
- a `z80_machine.h` with the `contend_read`, `contend_read_no_mreq` and `contend_write_no_mreq` macros (Fuse's: page contended → add `ula_contention[tstates]`, then add the time)

The per-access contention hook PLAN.md §3 requires is those three macros plus `readbyte`/`writebyte`. Only HOME RAM pages are contended (DOCK and EXROM never) because the machine says so, not the core.
