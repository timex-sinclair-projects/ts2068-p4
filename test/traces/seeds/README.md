# Trace seeds

The Pico flash and SD card contents each trace started from, minus what's already in the pinned firmware. The P4 replay must start from exactly this state, or the bytes the firmware sends (catalogs, menus) differ.

**Flash** (`/` on the Pico) for both traces:

- `config.ini` from `firmware/src/config.ini`, with `"TELEMETRY": true` (pico_host's `build_root` sets it).
- `words.txt` from `firmware/src/words.txt`.
- `assets/*.tap` from `firmware/src/assets/` (generated by `firmware/tools/build-basic.sh`).
- Then the trace's own `flash/` folder on top. `fuse-smoke/flash/assets/nofile.tap` replaces the stock one: it's `fuse_smoke.py`'s test program.

**SD card** (`/sd`):

- `fuse-smoke`: `fuse-smoke/sd/` only.
- `zesarux-smoke`: `firmware/SD card/help/` copied to `/sd/help/`, then `zesarux-smoke/sd/`, plus an **empty** folder `/sd/TAP/GAMES` (git can't store an empty folder, so the installer makes it).

Nothing else may be on the card: the firmware lists folders, and an extra file changes what it sends.
